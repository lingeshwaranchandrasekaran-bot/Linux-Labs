# Linux Basic File and Directory Commands

## Task 1

- Displayed the current working directory using `pwd`.
- Listed files and directories using `ls`.
- Created a directory using `mkdir`.
- Changed directory using `cd`.
- Created a file using `touch`.
- Added text to a file using `echo`.
- Displayed file contents using `cat`.
- Copied a file using `cp`.
- Renamed a file using `mv`.

## Commands Used

```text
pwd
ls
mkdir linux-lab
cd linux-lab
touch test.txt
echo "Linux Lab Task 1" > test.txt
cat test.txt
cp test.txt backup.txt
mv backup.txt test-backup.txt
ls
```
